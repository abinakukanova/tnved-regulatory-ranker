## Стэк

- BM25
- BAAI/bge-m3
- Reciprocal Rank Fusion
- BAAI/bge-reranker-v2-m3

## Запуск

0. Скачайте модели с Hugging face и положите в одну папку:

```text
models/
├── bge-m3/
└── bge-reranker-v2-m3/
```

1. Установите зависимости
```bash
pip install -r requirements.txt
```

2. Запустите ранкер

```bash
python run.py --data ./data --out ./out
```

Полная команда:

```bash
python run.py \
  --data ./data \
  --out ./out \
  --models ./models \
  --bm25-k 60 \
  --dense-k 60 \
  --candidate-k 80 \
  --rerank-batch-size 16
```

## Описание подхода

Используется гибридный подход: BM25 + bge-m3

```
                    Декларация
                         |
              +----------+----------+
              |                     |
             BM25                 BGE-M3
              |                     |
          lexical              semantic
          retrieval             retrieval
              |                     |
              +----------+----------+
                         |
                        RRF
                         |
                 candidate set
                         |
                 BGE-reranker-v2-m3
                         |
                       Top-10
```

`tnved_knowledge.txt` используется как доп. источник информации, добавляется к тексту регуляций. Информация из справочника соотносится с кодом регуляции. Чаще всего, текст из справочника повторяет текст регуляции, но иногда содержит новую уточняющую информацию.

Ранкер по качеству лучше, но работает дольше.


## Возможные улучшения

Попробовать создать rule-based признаки, на основе справочного дампа, и использовать их, чтобы штрафовать/бустить кандидато. Например, можно рассмотреть такие признаки:
1. к какому разделу справочника относятся (животные, продукты, изделия и т.д.)
2. материал товара
3. функциональное назначение товара
